# Aden Kitchen Challenge prototype scope

This plan is newly added: the repository's AGENTS.md references a plan, but none existed at the inspected base commit.

- Add an accessible entry point after the home-page recipe discovery section.
- Add `/play` using the existing Next.js App Router and branding.
- Host the supplied shiro game locally under `/kitchen/index.html`, isolated in a sandboxed frame. Keep its original vector art, responsive layout, modes, educational feedback and round scoring.
- Require no account or personal information. Do not persist scores, award redeemable value, or call checkout/rewards/payment services.
- Preserve all existing home-page scenes, waitlist, ordering redirects and release configuration.
- Test pantry selection, sequence, simmer, serving, replay, mobile overflow, reduced motion and isolation. Run existing unit, type and lint checks. Record blocked checks honestly.
- Do not publish, deploy, push, create rewards, or alter financial terms. A native React state rewrite, additional dishes, culinary approval and server-verified rewards remain separate future work.
